# Audio licences

Every sound in this project is synthesised in code by `tools/sound.py` (sine waves, seeded noise and simple filters):
music, room tones, footsteps, pops, the fax shriek. No recordings, samples, loops or downloaded files are used, so
there is nothing to license: the soundtrack is original work made for this project.
